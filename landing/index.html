Self-hosting, made easy

Clone the repo, run one make target, open https://newsblur. The web app, workers, databases and proxy all come up together, on Linux or Windows.

See the commands

Features upstream doesn’t have

Two thousand unread stories instead of a hundred, real drag & drop, one-click mark as read, a new dark theme and more.

Browse the list

Fast, because there is no AI

No model calls and no summaries to wait for. The server spends its time on your feeds, so lists and stories open immediately.

Why it’s quick

What you get that upstream doesn’t offer

Everything below is already in NewsBlurMod. Nothing is a roadmap item.

2,000 unread stories

The cap of 100 unread stories is gone. The limit is now 2000, so a week away doesn’t drop stories on the floor.

Drag & drop organizing

Reorder and reorganize feeds and folders by dragging. The forced alphabetical sort in the sidebar is disabled.

Bigger grid previews

Grid mode uses larger preview images, fitted with “contain” instead of “fill” so nothing gets cropped.

A new dark theme

Deep, even and easy on the eyes at night. It is the look of the preview above.

One-click mark as read

A single click on an unread count marks that feed as read.

Ready for Feedxcavator

WebSub is on by default, push throttling is off and subscription leases never expire, so it pairs cleanly with Feedxcavator.

Runs on Windows

Use Docker Desktop, or Docker Engine inside WSL2. No spare Linux box required.

Lean by default

Discovery indexing and the Prometheus middleware are switched off, so less work happens in the background.

No AI. That’s the feature.

NewsBlurMod has no AI integrations. Nothing sits between you and your stories waiting for a model to answer.

  • No model calls in the reading path, so a story opens as soon as you click it.
  • No summaries or rewrites of what the publisher wrote. You read the original.
  • No keys, quotas or subscriptions to set up for a smart layer you didn’t ask for.
  • Less background work: discovery indexing and metrics middleware are off.

From clone to reading in a few commands

You need Docker, git and make. Everything else is built for you.

Linux or WSL2
# 1. Make the server available under 
#    the "newsblur" name in your net or hosts
git clone https://github.com/GChristensen/NewsBlurMod
cd NewsBlurMod
sudo make nb -f Makefile.unix
Windows, Docker Desktop
:: 1. add "127.0.0.1 newsblur" to the hosts file
::    C:\Windows\System32\drivers\etc\hosts
git clone -c core.autocrlf=false -c core.symlinks=true https://github.com/GChristensen/NewsBlurMod
cd NewsBlurMod
make nb -f Makefile.win
  1. Build. One make target builds the images, starts every container and bootstraps the database.
  2. Open https://newsblur in your browser and create an account.
  3. Subscribe and read. Import an OPML file to bring your feeds along.

Docker Desktop is fine for trying it out. For a long-running server use Linux, or Docker Engine inside WSL2. The README has the full prerequisites for each platform.
